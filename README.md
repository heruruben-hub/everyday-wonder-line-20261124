## What it does

`main.py` writes a single sentence to `/output/entry.txt` — one small everyday
moment made strange and new. It validates the gate first (one line, 1–200
characters, not only whitespace), then reads the file back and checks it
holds exactly what was written. Set `ENTRY_OUTPUT` to write somewhere else.

> The lift doors opened on a stranger humming my grandmother's lullaby, and for one floor neither of us said a word.

## Run it

```sh
python3 main.py
```
